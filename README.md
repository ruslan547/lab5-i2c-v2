# lab5-i2c — BMP180 по шине I2C на STM32F401RE

Лабораторная работа №5 по курсу «Аппаратно-программное обеспечение БПЛА».
Программная реализация работы с датчиком давления **BMP180** по интерфейсу
**I2C** на микроконтроллере **STM32F401RE** (регистровый доступ, CMSIS).

## Вариант

| Параметр | Значение |
|---|---|
| Частота шины | 200 кГц |
| Датчик | BMP180 (адрес 0x77: 0xEE – запись, 0xEF – чтение) |
| SCL | PA8 |
| SDA | PC9 |

Шина I2C формируется **программно** (bit-banging): PA8 и PC9 работают как
выходы с открытым стоком и подтяжкой к VDD. Аппаратный модуль I2C3 на этих
выводах модель Proteus не выводит на линии, поэтому протокол (START,
Repeated START, STOP, ACK/NACK, clock stretching) реализован в `Src/main.c`.
Внешние резисторы подтяжки 4,7 кОм на SCL и SDA к 3,3 В обязательны.

## Подключение индикатора LM016L

| Сигнал | Вывод МК |
|---|---|
| RS | PB2 |
| E | PB3 |
| D4…D7 | PB4…PB7 |
| RW | общий провод |

## Работа программы

1. Чтение регистра ID `0xD0` → `0x55`, на ЖКИ: `LCD OK! I2C OK!` / `BMP180 OK! ID=55`.
2. Чтение 11 калибровочных коэффициентов (`0xAA…0xBF`).
3. Цикл (500 мс): температура (`0x2E` → `0xF4`, 5 мс, чтение `0xF6/0xF7`),
   давление (`0x34` → `0xF4`, 5 мс, чтение `0xF6/0xF7/0xF8`), компенсация по
   алгоритму документации BMP180. На ЖКИ: `T= 25.0 C` и `P=101325Pa 760mm`.

Каждый байт читается отдельной транзакцией
`S EE A <reg> A Sr EF A <data> N P`, запись: `S EE A F4 A <cmd> A P`.

## Частота SCL

Полупериод SCL = `SystemCoreClock / (2·F_SCL)` = 210 тактов при 84 МГц, из них
`I2C_OVERHEAD` тактов уходит на вызовы и обращения к GPIO, остальное — цикл
задержки на ассемблере (не зависит от уровня оптимизации). Если по
осциллографу частота отличается от 200 кГц, подстроить `I2C_OVERHEAD`.

STM32CubeIDE → `File → Import → Existing Projects into Workspace` →
